# 국내 주식 수렴·돌파 전략 백테스트

KOSPI·KOSDAQ 전 종목(상장폐지 포함 시도)을 대상으로 **수렴 → 거래량 동반 돌파** 전략을
포트폴리오 단위로 검증하는 파이썬 코드입니다. 기존 1차 스캐너(`krx_convergence_scan.py`)를
최종 수익률 백테스트까지 확장하면서, 검토에서 나온 문제를 고쳤습니다.

> 투자 권유가 아닙니다. 과거 성과는 미래 수익을 보장하지 않습니다.

## 빠른 시작

```bash
pip install -r requirements.txt

# 1) 코드가 도는지 가짜 데이터로 확인 (1초)
python run_backtest.py --source synthetic

# 2) 앞 200종목만 실제 데이터로 시험 (FinanceDataReader)
python run_backtest.py --source fdr --limit 200

# 3) 전체 종목 (처음엔 다운로드에 시간이 오래 걸림, cache/ 에 저장돼서 두 번째부터 빠름)
python run_backtest.py --source fdr

# 4) 직접 받은 KRX CSV 폴더 사용 (실제 거래대금 열 Value 포함 권장)
python run_backtest.py --source csv --data-dir krx_csv
```

Google Colab에서는 저장소를 clone 한 뒤 같은 명령 앞에 `!` 를 붙이면 됩니다.

### 깃허브에서 바로 실행 (설치 없음)

1. 저장소 위쪽 **Actions** 탭 → 왼쪽 **백테스트 실행**
2. 오른쪽 **Run workflow** → 소스·종목 수 입력 → 초록 **Run workflow** 버튼
3. 실행이 끝나면(초록 체크) 클릭 → 화면에 요약 리포트, 맨 아래 **Artifacts → backtest-results** 에서 결과 파일 전체 다운로드

한 번 받은 주가 데이터는 캐시에 저장돼서 다음 실행은 더 빠릅니다.

## 검토 후 고친 점

| 문제 | 수정 |
|---|---|
| 돌파일 양봉이 수렴 지표(가격 범위·ATR)를 키워 좋은 신호가 빠짐 | **수렴은 t-1까지**, 추세·돌파·거래량은 t 기준으로 분리 |
| 손절가 수식 오타 | 손절가 = 저항선 **−** 0.5 × ATR(14) |
| 같은 날 손절과 +2R이 모두 찍히면 순서 불명 | **손절 먼저** 가정 (성과 과대평가 방지) |
| 갭 하락 시 손절가 체결 가정 | 시가가 손절가 아래면 **시가 체결** → 1R보다 큰 손실 반영 |
| 동시 보유 제한 없음 | 최대 8종목, 같은 날 신호 여러 개면 거래량 배수 큰 순 |
| 비용 미반영 | 수수료 0.015%, 매도세 0.20%, 슬리피지 0.2% (설정 가능) |
| 월 10만 원 입금이 수익률을 부풀림 | 입금 효과를 뺀 **시간가중수익률(TWR)** 로 CAGR·MDD 계산 |
| 현재 관리종목 상태로 과거를 거르면 미래 정보 사용 | 현재 상태로 거르지 않음. 당시 이력을 `--exclude` CSV로 넣을 수 있음 |
| ATR 수렴 조건이 5년·200종목에서 0.16%만 충족 → 신호 2건 | 하루 변동폭(TR) 5일 평균 ÷ 20일 평균으로 변경 |
| 저항선 정의 모호 | 직전 10거래일 **고가** 최고값 (`breakout_basis="close"` 로 변경 가능) |
| 벤치마크 없음 | 같은 기간 KOSPI·KOSDAQ 지수 수익률·MDD 비교 |

## 전략 규칙 (기본값, `krxbt/config.py`)

**종목 필터**: 보통주만(우선주·스팩·ETF·리츠 제외), 직전 20거래일 평균 거래대금 ≥ 20억, 거래량 0(거래정지)일 제외

**수렴 (t-1 기준, 모두 충족)**
- 최근 10일 가격 범위 ≤ 그 직전 10일 범위 × 0.70
- 하루 변동폭(True Range)의 최근 5일 평균 ÷ 최근 20일 평균 ≤ 0.75
  (원문의 'ATR(14)의 5일 평균 ÷ 20일 평균'은 ATR이 이미 평활된 값이라 거의 충족되지 않아 변경. `atr_ratio_mode="smoothed"` 로 원문 방식 사용 가능)

**추세·돌파 (t 기준)**
- 종가 > MA20, MA20 > 5거래일 전 MA20
- 종가 ≥ 직전 10일 최고가 × 1.005
- 거래량 ≥ 직전 20일 평균 × 1.5

**진입 (t+1 시가)**
- 시가 > 신호일 종가 × 1.02 → 추격 안 함
- 시가 ≤ 저항선 → 진입 취소
- 손절가 = 저항선 − 0.5 × ATR(14), 진입가 대비 손절 위험 > 6% → 진입 안 함
- 수량 = 계좌 × 0.5% ÷ (진입가 − 손절가), 한 종목 계좌 25% 이하, 현금 한도

**청산**
- 저가가 손절가 터치 → 손절 (갭 하락이면 시가)
- +2R 도달 → 절반 익절
- 종가 < MA10 → 다음 날 시가 전량 청산
- 데이터가 끊긴 종목(상장폐지 등) → 마지막 종가로 청산 (`delisted_exit="zero"` 로 바꾸면 전액 손실로 보수적 처리)

**계좌**: 초기 700만 원, 매월 첫 거래일 10만 원 입금, MDD 10% 도달 시 리포트에 경고

## 과최적화 방지

```bash
# 파라미터 민감도: 주변 값에서도 성과가 비슷한지 확인 (최적값 고르기용 아님)
python sensitivity.py --source fdr --limit 500

# 기간 분리: 앞 3년으로 규칙 점검 → 뒤 2년은 한 번만 검증
python run_backtest.py --source fdr --start 2021-10-25 --end 2024-10-25 --out results/in_sample
python run_backtest.py --source fdr --start 2024-10-28 --end 2026-10-23 --out results/out_sample
```

## 알려진 한계

- FinanceDataReader의 상장폐지 종목 가격 데이터는 일부만 받아질 수 있습니다 → `failed_tickers.csv` 확인. 많이 빠지면 결과가 낙관적입니다.
- 거래대금은 실제 값(`Value` 열)이 없으면 종가 × 거래량으로 근사합니다 (`coverage.csv` 의 `value_is_approx`).
- 관리종목·투자위험 지정 이력은 무료 소스로 자동 수집되지 않습니다. KRX에서 받아 `code,start,end` CSV로 만들어 `--exclude` 로 넘기세요.
- 일봉 기반이라 장중 체결 순서는 알 수 없고, 보수적 가정(손절 우선)을 씁니다.
- 증권거래세율은 시기·시장별로 달라서 기본값 0.20%는 가정입니다. 실제 세율로 `config.py` 를 조정하세요.
- 단주(1주 미만)·호가 단위는 반영하지 않았습니다.
